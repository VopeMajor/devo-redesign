These are ICON SHEETS for the systems of DEVO, a gothic game about time whose menu imitates the Star Rail Map of Honkai: Star Rail. The attached ref-mapa.jpg is the reference: in it, each location is a small, beautifully rendered 3D-looking object (a planet, a ship, a station) floating with soft glow. Make each icon an object in exactly that rendering style: high-end painterly 3D game art, soft rim light, small glowing particles, materials of polished gold, ivory, deep blue enamel and a touch of the colour named for it. NOT pixel art, NOT flat vector.
Each sheet is a strict 3x3 grid of equal square cells (341 px each), no gaps, no borders, no grid lines. Every cell has the SAME plain flat background colour #0B1A3A (deep navy), with one object centred, filling about 70% of the cell, nothing touching the cell edges, no text, no labels, no numbers, no frames, no rings around the objects.
